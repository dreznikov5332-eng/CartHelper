# AutoKart

Клиентский Fabric-мод для Minecraft Java **1.21.11**. Помогает быстро поставить рельсу и вагонетку рядом с игроком.

- **Подсветка.** Мод следит за ближайшим игроком (до 12 блоков) и красными точками обводит верх блока, на который
  стоит поставить рельсу. Блок выбирается среди тех, до которых ты дотягиваешься (4.5 блока): мод считает урон
  взрыва вагонетки с TNT по формуле игры (с учётом стен на пути) и берёт место, где урон противнику максимальный,
  а твой урон как можно меньше. Если везде тебе достаётся не меньше, чем ему, подсветки нет. Броня, зачарования и
  эффекты в расчёте не учитываются. Место обновляется само, пока игрок двигается.
- **Цепочка предметов.** После каждого действия мод сам берёт в руку следующий предмет из списка. Действием считается:
  поставленная рельса, поставленная вагонетка с TNT, выстрел из лука или арбалета, правый клик огнивом.
  Пример: Лук, Рельсы, Вагонетка. Ты стреляешь, берутся рельсы, ты ставишь рельсу, берётся вагонетка, ты ставишь её, и стрела
  взрывает вагонетку. Берутся только предметы из хотбара.
  По умолчанию цепочка такая: Рельсы, затем Вагонетка с TNT, затем Лук (запасные: Огниво, потом Арбалет).
- **Меню.** Клавиша `K` открывает меню: включение мода, подсветки и автовыбора и список предметов. Кнопка «+ Добавить»
  добавляет предмет в конец списка (можно добавить только рельсы, вагонетку с TNT, лук, арбалет и огниво, до 6 штук).
  Кнопки в строке: `<` и `>` меняют предмет, `^` и `v` двигают, `x` удаляет. Кнопка слева в строке: «затем» значит
  новый шаг цепочки, «или» значит запасной предмет для предыдущего (берётся, если основного нет в хотбаре).
  Кнопки `-` и `+` меняют «осторожность»: 0 значит не считать урон по себе, 1 значит твой урон считается наравне с уроном
  противника, больше значит выбирать места безопаснее. Рядом с каждым пунктом есть стрелка `>`: нажми её, и вместо списка
  появится объяснение. Всё сохраняется сразу.
- Клавиша `H` быстро включает и выключает подсветку.
- Настройки лежат в `config/autokart.json`.

Нужны Fabric Loader и Fabric API для 1.21.11.

**Важно:** на многих серверах такие моды запрещены правилами. Используй только там, где это разрешено.

## Сборка

```
./gradlew build
```

Готовый файл появится в `build/libs/autokart-1.0.0.jar`.
